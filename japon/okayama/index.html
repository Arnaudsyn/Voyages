Se déplacer

Okayama est une base ferroviaire sur l’axe Shinkansen et pour rejoindre Shikoku. Préparer le trajet vers le jardin et séparer les bagages des heures de promenade.

Où dormir

Aucun hôtel précis n’est conservé pour cette étape. Une base proche de la gare simplifie un passage court ; choisir le centre si le séjour est plus long.

Repère de nos notes

Le jardin est la visite explicitement sauvegardée pour Okayama. Garder du temps pour les allées et les points de vue plutôt que d’en faire un simple arrêt photo.

Comment organiser l’étape

  1. Arrivée et dépôt des bagages.
  2. Kōraku-en sans trop serrer le temps de visite.
  3. Kurashiki sur une autre demi-journée si le programme le permet.
