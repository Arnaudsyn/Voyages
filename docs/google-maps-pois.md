# Ajouter vos lieux Google Maps

Le guide peut utiliser les liens individuels Google Maps et les coordonnées qu’ils permettent d’identifier. Il n’a pas d’accès automatique aux listes privées de votre compte.

## Le plus simple : une liste partagée par ville

1. Dans Google Maps, ouvrir **Enregistrés / Saved** et la liste souhaitée.
2. Ouvrir le menu **⋮**, puis **Partager la liste / Send a link to view**.
3. Autoriser la consultation par les personnes disposant du lien, puis copier le lien.
4. Donner le lien avec le nom de la ville. L’accès effectif à toute la liste devra être vérifié ; les pages Google Maps peuvent nécessiter une lecture dans le navigateur.

Les lieux étoilés ne sont pas partageables comme une liste ordinaire. On peut les ranger dans une liste personnalisée ou utiliser un export.

## Pour transmettre un fichier complet

Dans [Google Takeout](https://takeout.google.com/), désélectionner les produits, sélectionner **Saved / Enregistrés**, puis créer un export. Après téléchargement, transmettre les fichiers correspondant aux listes de voyage souhaitées. Le format reçu détermine les champs disponibles ; les coordonnées manquantes seront recherchées sans inventer d’emplacement.

Si les points sont dans **Google My Maps** : menu de la carte **⋮ → Exporter au format KML/KMZ**. Une couche peut aussi être exportée en CSV.

## Les informations qui enrichissent vraiment le guide

Pour chaque lieu, ajouter si possible :

- ville ou région et nom du lieu ;
- lien Google Maps individuel ;
- pourquoi il vous intéresse ;
- déjà visité, recommandé, avis mitigé ou simplement sauvegardé ;
- une courte note personnelle, une durée de visite ou une photo que vous souhaitez utiliser.

Les notes sur un hébergement ou un repas sont utiles sans les numéros de réservation ni les codes d’accès.
